## Working on now

- **[graph-graph](https://github.com/bshepp/graph-graph)** — do simple local graph rules at scale produce
  interesting emergent behavior? Sparse simulation, dimension analysis, pre-registered experiment waves.
- **[terravector](https://github.com/bshepp/terravector)** — terrain patch similarity search with
  decomposition-based embeddings and HNSW indexing, built on RESIDUALS.
- **[alcubierre](https://github.com/bshepp/alcubierre)** — reframing the warp-drive metric's exotic-matter
  requirement as a boundary (Casimir-like) effect. Phase-1 linearization verified symbolically and numerically.

## Selected work

| Project | What it is |
|---|---|
| **[RESIDUALS](https://github.com/bshepp/RESIDUALS)** | Differential feature detection in elevation models — 25 decomposition × 19 upsampling methods, built for archaeological prospection (Hopewell Road, Newark Earthworks). See also [residuals-visuals](https://github.com/bshepp/residuals-visuals). |
| **[3body-poisson-algebra](https://github.com/bshepp/3body-poisson-algebra)** | The pairwise Poisson algebra of the *N*-body problem — the *N*=3 dimension sequence 3, 6, 17, 116… holds across potentials and mass ratios. Dashboard → [nbody.briansheppard.com](https://nbody.briansheppard.com). |
| **[ESTA](https://github.com/bshepp/ESTA)** | Local LLM wrapper exposing auditable internal state (token confidence, refusal-direction projection) alongside OpenAI-compatible responses. |
| **[rna-joint-normality](https://github.com/bshepp/rna-joint-normality)** | Proof that hairpins and basepairs in random RNA secondary structures are asymptotically jointly normal — a Bu–Kauers–Zeilberger conjecture. |
| **[integer-sequence-visualizer](https://github.com/bshepp/integer-sequence-visualizer)** | Live OEIS visualizer with a null-model layer: is the structure in the sequence, or in the rendering? |
| **[fpaa-tools](https://github.com/bshepp/fpaa-tools)** | Python tooling for Anadigm FPAAs on a Raspberry Pi HAT — part of the physical-learning-substrates line. |
